Creating Omada Controller

Installing & Configuring OMV Extras and Docker

Installing OMV Extras:

Systems -> Plugins -> Install openmediavault-compose

Configuring Compose:

Services -> Compose -> Settings

Set Docker Storage Path to:

/srv/dev-disk-by-uuid-(DISK-UUID)

Save -> Apply

Check if worked under:

Services -> Compose

Options for Files, Services, Images, etc. should show up.



Installing Omada Controller on Docker Compose

Access OMV over terminal or use SSH.

sudo mkdir -p /srv/dev-disk-by-uuid-(DISK-UUID)/appdata/omada/data

And:

sudo mkdir -p /srv/dev-disk-by-uuid-(DISK-UUID)/appdata/omada/logs

On OMV Webinterface:

Services -> Compose -> Files -> Add

Name: omada-controller

Add Compose/YAML File:


services:
    omada-controller:
        container_name: omada-controller
        image: mbentley/omada-controller:6.2

        restart: unless-stopped
        stop_grace_period: 60s

        network_mode: host

        ulimits:
             nofile:
             soft: 4096
            hard: 8192

        environment:
            - MANAGE_HTTP_PORT=8088
            - MANAGE_HTTPS_PORT=8043
            - PORTAL_HTTP_PORT=8088
            - PORTAL_HTTPS_PORT=8843
            - UPGRADE_HTTPS_PORT=8043
            - PORT_APP_DISCOVERY=27001
            - PORT_DISCOVERY=29810
            - PORT_MANAGER_V1=29811
            - PORT_ADOPT_V1=29812
            - PORT_UPGRADE_V1=29813
            - PORT_MANAGER_V2=29814
            - PORT_TRANSFER_V2=29815
            - PORT_RTTY=29816
            - PORT_DEVICE_MONITOR=29817
            - SHOW_SERVER_LOGS=true
            - SHOW_MONGODB_LOGS=false
            - TZ=Europe/Berlin

        volumes:
            - /srv/dev-disk-by-uuid-(DISK_UUID)/appdata/omada/data:/opt/tplink/EAPController/data
            - /srv/dev-disk-by-uuid-(DISK_UUID)/appdata/omada/logs:/opt/tplink/EAPController/logs

Save and Check Compose File if everything is alright, click Up.

Check if Container is running under:

Services -> Compose -> Services

Should show up as running.



Accessing Omada Controller UI

Open Omada Controller Webinterface via: https://your-omv-ip:8043

Setup Wizard will start, create Admin Account and adopt Omada Hardware.
