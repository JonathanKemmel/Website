Creating a Controller

A self-hosted Omada Controller provides centralized management for all network devices. It enables unified configuration, real-time monitoring, and simplified troubleshooting across switches, routers, and access points without relying on cloud services.

  • First Check if Compose File is correct, than put Stack UP

Planning Network Structure

  • VLAN 10 (LAN): PCs, NAS, normal clients → Internet access
  • VLAN 20 (IoT): ESPHome, Tasmota, Smart Devices → No access to other VLANs, optional internet
  • VLAN 30 (Mgmt): Switch, AP, Router, Hypervisor → Isolated, no internet
  • VLAN 40 (Server): Home Assistant, Proxmox, NAS → Internet access, restricted access to LAN
  • VLAN 50 (Guest): WLAN guests → Internet only, no access to local networks

Setting Up Network Structure in Software

Configure VLANs, ACLs, and routing policies in the Omada Controller to implement the planned network segmentation. This includes setting up firewall rules, port assignments, and inter-VLAN communication restrictions.
