NAS (Network Attached Storage)

Hardware:

  • ASUS PRIME A320M-K Motherboard
  • AMD Ryzen 5 2600 (6-Core)
  • 16GB DDR4 RAM (2x8GB Corsair)
  • 250GB NVMe SSD (OS)
  • 4TB HDD (Storage)
  • 2TB HDD (Storage)
  • NVIDIA GeForce GT 710

Use Case:

  • Centralized file storage for multiple devices
  • Backup solution
  • Low power consumption 24/7 operation
  • Easy management via OpenMediaVault web interface

Content:

  • Debian Installation
  • Install OpenMediaVault
  • Configure Storage
  • Setup Shared Folders

Debian Installation:

Prepare ISO:

  • Download Debian 13 netinst ISO
  • Write to Ventoy USB Drive

BIOS Settings:

  • Boot into BIOS
  • Enable AHCI (not Raid) for NVMe
  • Enable UEFI boot (recommended)
  • Disable secure boot
  • Save & reboot into USB installer

Debian 13 Minimal Install:

  • Boot installer: Select Install
  • Choose language, country, keyboard layout
  • Network Configuration:
    1. Select network interface (Ethernet preferred)
    2. If using DHCP, automatically IP
    3. If static IP:
      1. IP: 192.168.X.XXX
      2. Netmask: 255.255.255.0
      3. Gateway: 192.168.X.1
      4. DNS: 8.8.8.8
  • Set Hostname & Domain:
    1. Hostname: your-hostname (e.g., nasserver)
    2. Domain: leave empty
  • Set Root & User:
    1. Root password: strong one
    2. Create a user: your-username
  • Partition Disk:
    1. Guided → use entire disk
    2. Optional, choose LVM if expanded in future
    3. Confirm changes and write partitions
  • Package Selection:
    1. Deselect all except:
      1. SSH server
      2. Standard system utilities
    2. Do not install desktop environments for minimal OMV!!!
  • Install Grub:
    1. Install Grub on main disk (/dev/nvme0n1)
    2. Confirm installation
  • Finish & Reboot:
    1. Remove USB and reboot
    2. Log in with your user or root

Post-Install Essentials:

  • Update & Upgrade:
    1. sudo apt update && apt upgrade -y
    2. sudo reboot
  • Enable SSH:
    1. sudo systemctl enable ssh
    2. sudo systemctl start ssh
  • Install required tools:
    1. sudo apt install -y sudo curl gnupg lsb-release

Install OpenMediaVault:

Note: OMV 7 is designed for Debian 13

  • Add OMV Repo:
    1. sudo curl -fsSL https://packages.openmediavault.org/public/archive.key | sudo gpg --dearmor -o /etc/apt/trusted.gpg.d/openmediavault.gpg
    2. echo "deb https://packages.openmediavault.org/public arrakis main" | sudo tee /etc/apt/sources.list.d/openmediavault.list
    3. sudo apt update
  • Install OMV:
    1. sudo apt install openmediavault-keyring postfix -y
    2. sudo apt update
    3. sudo apt install openmediavault -y
  • Initialize OMV:
    1. sudo omv-initsystem
  • Access OMV Web GUI:
    1. Default URL: http://<your-server-ip>/
    2. Default credentials:
      1. Username: admin
      2. Password: openmediavault
    3. Change password immediately after login

Configure Storage:

Add and format drives in OpenMediaVault:

  • Network:
    1. Configure static IP if not done
    2. Disable IPv6 if unused
  • Storage:
    1. Add drives under Storage > Disks
    2. Wipe and create file systems (EXT4 recommended for simplicity)

Setup Shared Folders:

Create and configure network shares:

  • Shared Folders:
    1. Create shared folders on drives
    2. Assign permissions
  • SMB / NFS / FTP:
    1. Enable desired services under Services
    2. Create users for network access
  • Updates:
    1. Regularly check System > Update Management
  • Optional:
    1. Docker Plugin (omv-extras) for containers
    2. SnapRAID / MergerFS if needed for advanced storage
