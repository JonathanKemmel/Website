Website Development - Detailed Guide

HTML Commands Reference

Document Structure

  • <!DOCTYPE html> - Declares document as HTML5
  • <html> - Root element containing all HTML content
  • <head> - Contains metadata, title, links to CSS/JavaScript
  • <meta> - Defines metadata (charset, viewport, description)
  • <title> - Sets page title shown in browser tab
  • <link> - Links external resources (CSS stylesheets, favicons)
  • <script> - Embeds or references JavaScript code
  • <body> - Contains all visible page content

Semantic Structure Elements

  • <header> - Defines header section (logo, navigation)
  • <nav> - Navigation menu container
  • <main> - Main content area of the document
  • <section> - Thematic grouping of content
  • <article> - Self-contained content (blog post, news article)
  • <aside> - Sidebar or tangentially related content
  • <footer> - Footer section (copyright, links)

Text Content

  • <h1> to <h6> - Headings (h1 most important, h6 least)
  • <p> - Paragraph of text
  • <br> - Line break (self-closing)
  • <hr> - Horizontal rule/divider (self-closing)
  • <strong> - Important text (bold)
  • <em> - Emphasized text (italic)
  • <mark> - Highlighted text
  • <small> - Smaller text
  • <code> - Inline code snippet
  • <pre> - Preformatted text (preserves spacing)
  • <blockquote> - Block quotation

Lists

  • <ul> - Unordered list (bullet points)
  • <ol> - Ordered list (numbered)
  • <li> - List item
  • <dl> - Description list
  • <dt> - Description term
  • <dd> - Description definition

Links & Media

  • <a href="url"> - Hyperlink (href required)
  • <img src="url" alt="text"> - Image (src and alt required)
  • <video> - Embeds video player
  • <audio> - Embeds audio player
  • <iframe> - Embeds another webpage/document
  • <picture> - Responsive image container
  • <source> - Defines media resources for video/audio/picture

Tables

  • <table> - Defines a table
  • <thead> - Table header section
  • <tbody> - Table body section
  • <tfoot> - Table footer section
  • <tr> - Table row
  • <th> - Table header cell
  • <td> - Table data cell
  • <caption> - Table caption

Forms & Input

  • <form> - Form container (action, method attributes)
  • <input> - Input field (type: text, email, password, etc.)
  • <textarea> - Multi-line text input
  • <button> - Clickable button
  • <select> - Dropdown menu
  • <option> - Option in dropdown
  • <label> - Label for input field
  • <fieldset> - Groups form elements
  • <legend> - Caption for fieldset

Container & Layout

  • <div> - Generic block-level container
  • <span> - Generic inline container

Attributes (Apply to many elements)

  • id="unique-name" - Unique identifier
  • class="name" - CSS class name(s)
  • style="css" - Inline CSS styling
  • title="text" - Tooltip text
  • data-*="value" - Custom data attributes
  • aria-* - Accessibility attributes

CSS Definitions Reference

Text Styling

  • color - Text color (hex, rgb, hsl, named)
  • font-size - Text size (px, rem, em, %)
  • font-family - Font typeface
  • font-weight - Text thickness (normal, bold, 100-900)
  • font-style - Normal, italic, oblique
  • text-align - Horizontal alignment (left, center, right, justify)
  • text-decoration - Underline, line-through, none
  • text-transform - Uppercase, lowercase, capitalize
  • line-height - Space between lines
  • letter-spacing - Space between characters
  • word-spacing - Space between words

Background & Colors

  • background-color - Background color
  • background-image - Background image (url())
  • background-size - Image size (cover, contain, px, %)
  • background-position - Image position
  • background-repeat - Image repetition (repeat, no-repeat)
  • background - Shorthand for all background properties
  • opacity - Element transparency (0 to 1)

Box Model

  • margin - Outer spacing (margin-top, -right, -bottom, -left)
  • padding - Inner spacing (padding-top, -right, -bottom, -left)
  • border - Element border (width style color)
  • border-width - Border thickness
  • border-style - solid, dashed, dotted, none
  • border-color - Border color
  • border-radius - Rounded corners
  • width - Element width
  • height - Element height
  • max-width / min-width - Width constraints
  • max-height / min-height - Height constraints
  • box-sizing - border-box includes padding/border in size

Display & Positioning

  • display - block, inline, inline-block, flex, grid, none
  • position - static, relative, absolute, fixed, sticky
  • top / right / bottom / left - Position offsets
  • z-index - Stacking order (higher = front)
  • float - left, right, none (legacy layout)
  • clear - Clears floats
  • overflow - visible, hidden, scroll, auto
  • visibility - visible, hidden

Flexbox Layout

  • display: flex - Enables flexbox on container
  • flex-direction - row, column, row-reverse, column-reverse
  • justify-content - Main axis alignment (start, center, space-between, etc.)
  • align-items - Cross axis alignment (start, center, stretch)
  • align-content - Multi-line alignment
  • flex-wrap - wrap, nowrap, wrap-reverse
  • flex - Shorthand for flex-grow, flex-shrink, flex-basis
  • gap - Space between flex items

Grid Layout

  • display: grid - Enables grid on container
  • grid-template-columns - Defines column structure
  • grid-template-rows - Defines row structure
  • grid-gap / gap - Space between grid items
  • grid-column - Item column placement
  • grid-row - Item row placement
  • grid-area - Shorthand for row/column placement

Effects & Transforms

  • box-shadow - Drop shadow (x y blur spread color)
  • text-shadow - Text shadow (x y blur color)
  • transform - translate, rotate, scale, skew
  • transition - Animates property changes (property duration easing)
  • animation - Keyframe animations
  • filter - Visual effects (blur, brightness, contrast, etc.)

Pseudo-Classes

  • :hover - Mouse hover state
  • :active - Click/tap state
  • :focus - Keyboard focus state
  • :visited - Visited link state
  • :nth-child(n) - Selects nth child
  • :first-child - First child element
  • :last-child - Last child element
  • :not(selector) - Negation selector

Pseudo-Elements

  • ::before - Inserts content before element
  • ::after - Inserts content after element
  • ::first-letter - First letter of text
  • ::first-line - First line of text
  • ::selection - Selected text styling

CSS Variables (Custom Properties)

  • :root - Global scope for variables
  • --variable-name - Defines custom property
  • var(--variable-name) - Uses custom property

Responsive Design

  • @media - Media queries for responsive design
  • max-width / min-width - Screen size breakpoints
  • viewport units - vw (viewport width), vh (viewport height)

Units

  • px - Pixels (absolute)
  • % - Percentage of parent
  • em - Relative to parent font-size
  • rem - Relative to root font-size
  • vw / vh - Viewport width/height percentage
  • fr - Fraction unit (grid only)
