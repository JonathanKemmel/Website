Create Ubuntu VM (Programming)

Upload ISO:

  • Proxmox GUI → Datacenter → Storage(local) → ISO Images → Upload
  • Choose Ubuntu ISO file

Create VM:

  • Proxmox GUI → Create VM
  • Node: <your-host>
  • VM ID: auto
  • Name: ubuntu-dev
  • OS tab:
    1. Use uploaded Ubuntu ISO
    2. Leave other default
  • System tab:
    1. BIOS: default (OVMF only if UEFI is needed)
    2. Machine: default
    3. Qemu Agent: checked (enables better shutdowns & status)
  • Disk tab:
    1. Bus/Device: SCSI0 on VIRTIO-SCSI controller
    2. Disk size: <your-choice>
    3. Format: qcow2 or raw (raw slightly faster on SSD)
  • CPU tab:
    1. Sockest: 1
    2. Core: 4 (2 if host smaller)
  • Memory tab:
    1. Memory: 8192 (recommended for dev work)
  • Network tab:
    1. Bridge: vmbr0
    2. Model: VIRTIO (fast)
  • Finish → Start VM → Console → run Ubuntu installer

Post-install:

  • Update the guest and install typical dev tools:
    1. sudo apt update && sudo apt upgrade -y
    2. sudo apt install -y build-essential git curl qemu-guest-agent
  • Install docker:
    1. sudo apt install -y ca-certificates gnupg lsb-release
    2. curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /usr/share/keyrings/docker-archive-keyring.gpg
    3. echo \ "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/docker-archive-keyring.gpg] \ https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" | \ sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
    4. sudo apt update
    5. sudo apt install -y docker-ce docker-ce-cli containerd.io
    6. sudo usermod -aG docker $USER
  • Install code-server (VS Code in browser) if remote IDE needed:
    1. curl -fsSL https://code-server.dev/install.sh | sh

Make a template:

  • Once your done, right click VM → clone
  • right click cloned VM → convert to template
  • Now your able to clone fresh dev VMs quick

Create Kali VM (Hacking/Security)

Important safety note:

  • Treat Kali as a risky toolkit
  • Keep it isolated from your main LAN
  • Only use it on systems/networks you own or have explicit permission to test

Upload ISO:

  • Proxmox GUI → Datacenter → Storage(local) → ISO Images → Upload
  • Choose Kali ISO file

Create isolated network without physical NIC:

  • Proxmox GUI → Datacenter → Node → System → Network → Create → Linux Bridge
  • Name: vmbr1
  • Leave rest empty
  • This way Kali can only talk to VMs on isolated Bridge (vmbr1)

Create VM:

  • Proxmox GUI → Create VM
  • Node: <your-host>
  • VM ID: auto
  • Name: kali-lab
  • OS tab:
    1. Use uploaded Kali ISO
    2. Leave other default
  • System tab:
    1. BIOS: default (OVMF only if UEFI is needed)
    2. Machine: default
    3. Qemu Agent: checked (enables better shutdowns & status)
  • Disk tab:
    1. Bus/Device: SCSI0 on VIRTIO-SCSI controller
    2. Disk size: <your-choice>
    3. Format: qcow2 or raw (raw slightly faster on SSD)
  • CPU tab:
    1. Sockest: 1
    2. Core: 4 (2 if host smaller)
  • Memory tab:
    1. Memory: 8192 (recommended for dev work)
  • Network tab:
    1. Bridge: vmbr1 (isolated bridge, no Network)
    2. Model: VIRTIO (fast)
  • Finish → Start VM → Console → run Kali installer
