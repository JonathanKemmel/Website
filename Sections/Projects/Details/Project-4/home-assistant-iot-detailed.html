Important Keywords

  • platform: - Specifies the component type
  • pin: - GPIO pin number
  • name: - Display name in Home Assistant
  • id: - Internal reference ID
  • on_press / on_release: - Button events
  • update_interval: - Sensor reading frequency
  • inverted: - Inverts logic level
  • mode: - Pin mode (INPUT, OUTPUT, INPUT_PULLUP)

Common Platforms

  • gpio - Direct pin control
  • dht - DHT11/DHT22 temperature/humidity sensors
  • dallas - DS18B20 temperature sensors
  • ledc - PWM output for ESP32
  • adc - Analog to digital converter
  • i2c - I2C bus devices
  • spi - SPI bus devices

C++ Syntax Reference (Arduino / ESP-IDF)

Basic Arduino Structure

#include <Arduino.h>

void setup() {
  // Runs once at startup
  Serial.begin(115200);
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
  // Runs continuously
  digitalWrite(LED_BUILTIN, HIGH);
  delay(1000);
  digitalWrite(LED_BUILTIN, LOW);
  delay(1000);
}

GPIO Control

// Pin modes
pinMode(pin, INPUT);
pinMode(pin, OUTPUT);
pinMode(pin, INPUT_PULLUP);

// Digital I/O
digitalWrite(pin, HIGH);  // Set high
digitalWrite(pin, LOW);   // Set low
int value = digitalRead(pin);

// Analog I/O
int value = analogRead(A0);  // 0-4095 on ESP32
analogWrite(pin, value);     // PWM output

PWM (LED Dimming)

const int ledPin = 5;
const int freq = 5000;
const int ledChannel = 0;
const int resolution = 8;

void setup() {
  ledcSetup(ledChannel, freq, resolution);
  ledcAttachPin(ledPin, ledChannel);
}

void loop() {
  for(int duty = 0; duty <= 255; duty++) {
    ledcWrite(ledChannel, duty);
    delay(10);
  }
}

Interrupts

const int buttonPin = 0;
volatile bool buttonPressed = false;

void IRAM_ATTR handleInterrupt() {
  buttonPressed = true;
}

void setup() {
  pinMode(buttonPin, INPUT_PULLUP);
  attachInterrupt(digitalPinToInterrupt(buttonPin), 
                  handleInterrupt, FALLING);
}

void loop() {
  if (buttonPressed) {
    buttonPressed = false;
    // Handle button press
  }
}

Python Syntax Reference (MicroPython)

Basic Structure

import machine
import time

# No setup() or loop() - just sequential code
led = machine.Pin(2, machine.Pin.OUT)

while True:
    led.on()
    time.sleep(1)
    led.off()
    time.sleep(1)

GPIO Control

from machine import Pin

# Setup pins
button = Pin(0, Pin.IN, Pin.PULL_UP)
led = Pin(2, Pin.OUT)

# Digital output
led.on()
led.off()
led.value(1)  # Same as on()
led.value(0)  # Same as off()

# Digital input
if button.value() == 0:
    print("Button pressed")

# Analog input (ADC)
from machine import ADC
adc = ADC(Pin(34))
adc.atten(ADC.ATTN_11DB)  # Full range: 0-3.3V
value = adc.read()  # 0-4095

PWM Control

from machine import Pin, PWM

led = PWM(Pin(5))
led.freq(1000)  # Set frequency to 1kHz

# Fade LED
for duty in range(0, 1024):
    led.duty(duty)
    time.sleep_ms(1)

for duty in range(1023, -1, -1):
    led.duty(duty)
    time.sleep_ms(1)

Temperature Sensor (DHT22)

import dht
from machine import Pin
import time

sensor = dht.DHT22(Pin(4))

while True:
    sensor.measure()
    temp = sensor.temperature()
    humidity = sensor.humidity()
    print('Temperature: {}°C'.format(temp))
    print('Humidity: {}%'.format(humidity))
    time.sleep(2)

Timers

from machine import Timer

def callback(timer):
    print("Timer triggered")

# Create timer (ID, period in ms, callback)
timer = Timer(0)
timer.init(period=1000, mode=Timer.PERIODIC, callback=callback)

Interrupts

from machine import Pin

def handle_interrupt(pin):
    print("Interrupt triggered on pin", pin)

button = Pin(0, Pin.IN, Pin.PULL_UP)
button.irq(trigger=Pin.IRQ_FALLING, handler=handle_interrupt)

Common Modules

  • machine - Hardware control (Pin, PWM, ADC, I2C, SPI, Timer)
  • network - WiFi and network connectivity
  • time - Time and sleep functions
  • dht - DHT temperature/humidity sensors
  • onewire - OneWire protocol (DS18B20)
  • ds18x20 - DS18B20 temperature sensor
  • neopixel - WS2812 LED control
  • socket - Network sockets

Key Differences from Regular Python

  • Limited standard library (no numpy, pandas, etc.)
  • Direct hardware access via machine module
  • Memory constraints - careful with large data structures
  • No threading (but has async/await support)
  • Use time.sleep_ms() instead of time.sleep() for milliseconds
  • String formatting: 'Value: {}'.format(x)
  • Limited floating point precision

Useful Functions

# Time functions
time.sleep(1)        # Sleep 1 second
time.sleep_ms(100)   # Sleep 100 milliseconds
time.sleep_us(10)    # Sleep 10 microseconds
time.ticks_ms()      # Get millisecond counter

# Memory management
import gc
gc.collect()         # Force garbage collection
gc.mem_free()        # Get free memory

# System functions
import machine
machine.reset()      # Reset the device
machine.freq()       # Get CPU frequency
machine.freq(240000000)  # Set CPU to 240MHz
