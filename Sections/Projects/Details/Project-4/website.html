Install Extensions in VS Code:

  • Live Server: For real-time preview of your website in the browser.
  • Prettier: For automatic code formatting and improved readability.
  • HTML CSS Support: For better code completion and syntax highlighting.
  • Color Highlight: To visualize color codes directly in the editor.
  • Path Intellisense: For easier linking of files and assets.

Writing HTML Code

  • <html> - Defines the root of an HTML document
  • <head> - Contains metadata, title, and links to stylesheets/scripts
  • <body> - Contains the visible page content
  • <header> - Defines a header section for navigation/branding
  • <nav> - Defines a navigation menu
  • <main> - Contains the main content of the document
  • <section> - Groups related content together
  • <div> - Generic container for grouping elements
  • <h1> to <h6> - Heading tags (h1 largest, h6 smallest)
  • <p> - Defines a paragraph of text
  • <a> - Creates hyperlinks with href attribute
  • <ul> / <ol> / <li> - Creates unordered/ordered lists with list items
  • <img> - Embeds images with src and alt attributes
  • <button> - Creates interactive buttons
  • <form> - Defines a form for user input
  • <input> - Creates input fields (text, email, password, etc.)
  • <span> - Inline container for styling text portions

Designing with CSS

  • color - Sets text color
  • background-color - Sets background color
  • font-size - Controls text size
  • font-family - Defines the font type
  • margin - Creates space outside an element
  • padding - Creates space inside an element
  • border - Adds border around elements
  • width / height - Sets element dimensions
  • display - Controls element display behavior (block, inline, flex, grid)
  • position - Sets positioning method (static, relative, absolute, fixed)
  • flex / grid - Modern layout systems
  • text-align - Aligns text (left, center, right)
  • box-shadow - Adds shadow effects
  • border-radius - Rounds corners
  • transition - Animates property changes
  • hover - Applies styles on mouse hover
  • :root / --variables - Defines CSS custom properties
