Setup and Installation:

How to Install and Setup Proxmox VE on Your Server:

  • Download Proxmox VE ISO from the official website.
  • Create a bootable USB drive using tools like Rufus or Etcher.
  • Boot the server from the USB drive and follow the installation prompts.
  • On Target Hard-Disk:
    1. hdsize: Full Disk Size
    2. swapsize: Swap Size should match RAM Size
    3. maxroot: Maximum Root Partition Size (leave Room for backups/VMs)
    4. minfree: 2GB (Reserved Space to prevent full Disk)
    5. => leaves the rest for VM/CT Storage
  • Configure network settings (recommend static IP) and set a strong root password during installation.
  • After installation, access the Proxmox web interface via https://your-proxmox-ip:8006.
  • Post Install:
    1. Update Proxmox VE to the latest version
    2. Enable No-Subscription Repository
    3. Enable Firewall, configure if needed
      1. Security and Maintenance:
      2. Enable 2FA on Login
      3. Schedule regular backups (atleast for important things)
      4. Setup Update and Upgrade monthly

Install MyDokuWiki:

How to Install MyDokuWiki on Proxmox VE:

  • Log in to the Proxmox web interface and download template (recommended ubuntu-24.04-standard-...)
  • Create a new Linux Container.
    1. Unprivileged Container: check
    2. Root Disk: 8GB
    3. CPU: 1 core
    4. Memory & Swap: 512MB
    5. Start at Boot: Check optional
  • Inside LXC Terminal Update and Install Web Stack:
    1. apt update && apt upgrade -y
    2. apt install apache2 php php-gd php-xml php-json php-mbstring libapache2-mod-php unzip wget nano ufw -y
    3. systemctl enable apache2
  • Install myDokuWiki:
    1. cd /tmp
    2. wget https://download.dokuwiki.org/src/dokuwiki/dokuwiki-stable.tgz
    3. tar -xvzf dokuwiki-stable.tgz
    4. mv dokuwiki-*/ /var/www/html/dokuwiki
    5. chown -R www-data:www-data /var/www/html/dokuwiki
  • Access MyDokuWiki via http://<container-ip>/install.php in a web browser
  • Follow the on-screen instructions to complete the installation and configuration of MyDokuWiki
  • Now you can access it via http://<container-ip>/doku.php in a web browser
  • Configure UFW Firewall to allow HTTP traffic:
    1. ufw allow 80/tcp & 443/tcp
    2. ufw enable
  • Regularly update MyDokuWiki and the underlying OS to ensure security and stability
  • Setup an automated backup system for MyDokuWiki data (highly recommended)

MyDokuWiki USB Backup:

How to Set Up Automated USB Backups on Proxmox VE:

  • Connect a USB drive to the Proxmox server and identify it using the command line
  • Create a mount point for the USB drive, e.g., /mnt/usb
  • Mount the USB drive to the mount point and ensure it is accessible
  • Create a manual Backup via vzdump
  • Verify and Test Backup File
  • Create a backup script to back up the MyDokuWiki data directory to the USB drive (should include mount at start and unmount at the end)
  • Schedule the backup script to run at regular intervals using cron
  • Ensure that the backup process is working correctly by checking the contents of the USB drive after the first backup

Install Tailscale VPN Server:

How to Install Tailscale on Proxmox VE:

  • I used a VE-Helper-Script
  • After installation, access website link and configure Tailscale
  • Enable Subnet routing in LXC Shell (optional as Exit Node)
    1. sudo sysctl -w net.ipv4.ip_forwarding=1
    2. sudo tailscale up --advertise-routes=192.168.X.0/24 (--advertise-exit-node)
  • Register other devices, like phone and Laptop to access the VPN network

Setup Debian 12 VM template:

How to Create a Debian 12 VM Template on Proxmox VE:

  • In Proxmox WEB GUI, download Debian 12 netinst ISO
  • Create a VM, for me it was following configuration:
    1. Name: Debian-12-Template
    2. OS Type: Linux, Debian 12/Bookworm
    3. CD/DVD: Use the downloaded Debian 12 ISO
    4. Hard Disk: 12GB (or more if you want to install more software)
    5. CPU: 1 core (can be adjusted based on needs) and importantly set type to host
    6. Memory: 512MB (can be adjusted based on needs)
    7. Network: Default (Bridged mode)
  • Start the VM and go through the Debian installation process (set up a user, configure network, etc.)
  • After installation, log in to the VM and perform any necessary updates and configurations (e.g., install SSH server, set up firewall, etc.)
  • Once the OS is set up, shut down the VM and convert it into a template using the Proxmox web interface
  • Test cloning the template by creating a new VM from it
  • Use the Debian 12 template to quickly deploy new VMs with the same configuration in the future

Setup HDD as SMB-Share:

How to Set Up an HDD as an SMB-Share on Proxmox VE:

  • Connect an additional hard drive to the Proxmox server and identify it using the command line
  • Format and mount the hard drive on the Proxmox server
  • Install and configure Samba on the Proxmox server to share the mounted hard drive over the network:
    1. Install Samba: apt install samba -y
    2. Edit the Samba configuration file: nano /etc/samba/smb.conf
    3. Add:
      1. At the end of the file, add a new section for the shared folder:
      2. [Shared]
      3. path = /mnt/shared/files
      4. browseable = yes
      5. writable = yes
      6. read only = no
      7. guest ok = no
      8. valid users = @smbshare
      9. force group = smbshare
      10. create mask = 0664
      11. directory mask = 2775
    4. Restart the Samba service to apply the changes: systemctl restart smbd
  • Set appropriate permissions and user for the shared folder and access it from other devices on the network
  • Configure Proxmox Firewall to allow access to the SMB share if needed:
    • Protocol: TCP
    • Port: 445
    • Source: Your local network or specific IPs
    • Protocol: TCP
    • Port: 139
    • Source: Your local network or specific IPs
  • Test the SMB share from a client machine to ensure it is accessible and properly configured
    • On Windows: Open File Explorer and enter \\<proxmox-ip>\Shared
    • On Linux: Use the command line or file manager to access smb://<proxmox-ip>/Shared
