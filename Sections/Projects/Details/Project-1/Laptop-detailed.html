Laptop (Mobile Workstation)

Operating System

Prepare media and a minimal Debian 13 netinst for OpenMediaVault (OMV 7).

Prepare ISO

  • Download Debian 13 netinst ISO and verify its checksum (SHA256).
  • Write the ISO to a Ventoy USB drive.

BIOS Settings

  • Boot into BIOS.
  • Enable AHCI (not RAID) for NVMe.
  • Enable UEFI boot (recommended).
  • Disable Secure Boot.
  • Save & reboot into the USB installer.

Debian 13 Minimal Install

  1. Boot the installer and select Install. Choose language, country and keyboard layout.
  2. Network Configuration: select the network interface (Ethernet preferred). If DHCP is used, an IP is assigned automatically.
  3. If using a static IP, use these placeholders:
IP: 192.168.X.XXX
Netmask: 255.255.255.0
Gateway: 192.168.X.1
DNS: 8.8.8.8
  1. Set hostname: omvserver. Leave domain empty.
  2. Set a strong root password and create a user named admin.
  3. Partition disk: Guided → use entire disk. Optionally choose LVM for future expansion. Confirm changes and write partitions.
  4. Package selection: deselect desktop environments. Select only SSH server and standard system utilities. Do not install desktop environments for minimal OMV.
  5. Install GRUB on the main disk (for example /dev/nvme0n1), confirm and finish.
  6. Remove USB, reboot and log in with your user or root.

Post-Install Essentials

  • Update & Upgrade:
sudo apt update && sudo apt upgrade -y
sudo reboot
  • Enable SSH:
sudo systemctl enable ssh
sudo systemctl start ssh
  • Install required tools:
sudo apt install -y sudo curl gnupg lsb-release

Install OpenMediaVault

Note: OMV 7 is designed for Debian 13.

Add OMV Repo

sudo curl -fsSL https://packages.openmediavault.org/public/archive.key | sudo gpg --dearmor -o /etc/apt/trusted.gpg.d/openmediavault.gpg
echo "deb https://packages.openmediavault.org/public arrakis main" | sudo tee /etc/apt/sources.list.d/openmediavault.list
sudo apt update

Install OMV

sudo apt install openmediavault-keyring postfix -y
sudo apt update
sudo apt install openmediavault -y

Initialize OMV

sudo omv-initsystem

Access OMV Web GUI

Open the web GUI at:

http://<your-server-ip>/

Default credentials
Username: admin
Password: openmediavault
Change the password immediately after login.

Post-OMV Configuration

  • Network: configure a static IP if not already set; disable IPv6 if unused.
  • Storage: add drives under Storage > Disks, wipe and create filesystems (EXT4 recommended).
  • Shared Folders: create shared folders and assign permissions; create users for network access.
  • SMB/NFS/FTP: enable desired services in Services and verify firewall rules.
  • Updates: regularly check System > Update Management and apply updates.
  • Optional: install Docker plugin (omv-extras), SnapRAID or MergerFS for advanced storage setups.
