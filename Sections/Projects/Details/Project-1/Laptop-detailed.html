Arch Linux Setup & Configuration Notes

1. BIOS / Firmware Setup

  • Verified BIOS version: A2CN38WW(v2.06)
  • Enabled AMD SVM support (optional)
  • Set boot mode: UEFI
  • Disabled unnecessary devices or secure boot for simplicity
  • Hotkey Mode left default

2. Prepare Installation Media

  • Created Ventory USB drive
  • Copied latest Arch Linux ISO (2026.02.01)
  • Verified ISO integrity (SHA256)

3. Booting & Disk Setup

Booted from "EFI USB Device"

Verified live environment:

lsblk  # shows sda as HDD
ls /sys/firmware/efi  # directory does not exist (legacy/BIOS fallback)

Wiped HDD using:

wipefs -a /dev/sda
# Optional:
sgdisk --zap-all /dev/sda

Partitioning

  • Type: GPT
  • Created EFI + root partitions

Filesystem

  • Ext4 on root
  • EFI: FAT32
  • Optional: zRAM swap enabled

4. Arch Installation

Installed base system via archinstall tool

Chose:

  • Disk: sda
  • Filesystem: ext4
  • Bootloader: systemd-boot
  • Timezone: Europe/Berlin
  • Keyboard layout: de

Encountered package signature errors:

  • Resolved by updating ISO and skipping verification during install

Confirmed installation:

arch-chroot /mnt

System boots into installed Arch Linux

5. OpenSSH Installation & Configuration

Install OpenSSH:

sudo pacman -S openssh

Enable SSH daemon:

sudo systemctl enable sshd
sudo systemctl start sshd
sudo systemctl status sshd  # verify

Firewall (if ufw used):

sudo ufw allow 22/tcp

SSH login recommendations:

  • Use a normal user for login
  • Avoid root login over SSH for security

SSH configuration file:

sudo nano /etc/ssh/sshd_config

Key line:

PermitRootLogin no

Restart SSH after edits:

sudo systemctl restart sshd

6. GUI / XFCE Root Login Handling

Root login in XFCE4 is disabled by default. Recommended: log in as normal user and use sudo/pkexec for root tasks.

Optional: enable manual root login in LightDM:

sudo nano /etc/lightdm/lightdm.conf

Add under [Seat:*]:

greeter-show-manual-login=true

Set root password (if needed):

sudo passwd root

Restart LightDM:

sudo systemctl restart lightdm

Run apps as root safely:

sudo thunar       # file manager
pkexec gparted    # gparted

7. Disabling System Sounds / Bell

Terminal bell test:

echo -e "\a"

Disable PC speaker permanently:

sudo rmmod pcspkr
echo "blacklist pcspkr" | sudo tee /etc/modprobe.d/nobeep.conf

Disable audible bell in terminal:

Add to ~/.inputrc:

set bell-style none

Reload:

bind -f ~/.inputrc

XFCE GUI sound:

  • Settings → Notifications → disable event sounds
  • Settings → Keyboard → Behavior → uncheck "Audible bell"

Optional: mute all system audio

PulseAudio:

pactl set-sink-mute @DEFAULT_SINK@ 1

PipeWire:

pw-cli set-node-volume <node_id> 0

8. User & Root Management

Create normal user:

sudo useradd -m -G wheel myuser
sudo passwd myuser

Enable sudo for wheel group:

sudo EDITOR=nano visudo

Uncomment:

%wheel ALL=(ALL:ALL) ALL

SSH / GUI login:

  • Log in as normal user
  • Use sudo / pkexec for root actions

9. Network Configuration

Switched to NetworkManager for simplicity:

sudo systemctl enable NetworkManager
sudo systemctl start NetworkManager

10. Post-Install Essentials / Packages

Update system:

sudo pacman -Syu

Essential packages installed:

esphome, python, gcc, git, browser

Lightweight programming setup:

  • Programming focus: ESPHome, Python, HTML/CSS/JS, YAML
  • Browser: lightweight (qutebrowser / firefox with custom profile)

11. Notes & Issues

  • ISO mirrors can fail; switch mirrors if pacman -Syu is slow
  • Ensure proper Internet connectivity in live ISO for LSP installation
  • zRAM can be useful for low-RAM devices
  • Keep backup of working Arch ISO for future installs

IDE Setup for Low-Resource Development

Hardware

  • Laptop: Lenovo G50-45
  • OS: Arch Linux
  • RAM: 4GB
  • Storage: HDD

Step 1: Install VS Code Insiders (bare minimum)

sudo pacman -S code-insiders

Step 2: Configure VS Code Insiders for Low RAM / HDD

Create or edit ~/.config/Code - Insiders/User/settings.json:

{
    "telemetry.enableTelemetry": false,
    "telemetry.enableCrashReporter": false,
    "update.mode": "none",
    "files.watcherExclude": {
        "**/.git/objects/**": true,
        "**/.git/subtree-cache/**": true,
        "**/node_modules/**": true
    },
    "editor.minimap.enabled": false
}

Install only necessary extensions:

  • PlatformIO IDE (ESPHome)
  • Live Server (Web dev)
  • YAML (optional, for ESPHome YAML)

Step 3: Set up ESPHome

1. Create folder and virtual environment:

mkdir ~/esphome
cd ~/esphome
python -m venv venv

2. Activate virtual environment:

source venv/bin/activate

3. Upgrade pip inside venv (optional):

pip install --upgrade pip

4. Install ESPHome inside venv:

pip install esphome

5. Verify installation:

esphome version

Step 4: Install PlatformIO Core inside venv

With the venv active:

pip install platformio
platformio --version

PlatformIO IDE in VS Code Insiders should now detect PlatformIO Core automatically.

Step 5: Performance Tips for Low RAM / HDD

  • Keep VS Code Insiders windows minimal (one project at a time)
  • Disable unused extensions
  • Close terminals when not needed
  • HDD = slow build/upload → consider USB SSD for bigger ESPHome projects
