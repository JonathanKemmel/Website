Laptop — Full Detailed Guide

BIOS / Firmware & Media

  1. Enter BIOS/UEFI and set boot order to USB; enable AHCI if using NVMe/HDD.
  2. Create Ventoy USB and copy Arch Linux ISO; verify with SHA256.
  3. Boot to live environment and verify disks with lsblk.

Installation & Partitioning

  1. Partition disk (GPT) with EFI and root partitions.
  2. Create filesystems (ext4 for root, FAT32 for EFI) and mount them.
  3. Install base system (archinstall or manual) and set timezone/locale.

User, SSH & Post-Install

  • Create normal user and add to wheel group; configure sudo.
  • Install and enable OpenSSH; secure configuration (Disable root login if desired).
  • Install essential packages: python, git, esphome and a lightweight browser.

IDE & Performance

  • Use lightweight editors (neovim, geany) or code-server for remote editing.
  • Reduce file-watcher load and exclude large folders in IDE settings.
  • Enable zram/swap tuning for low-RAM systems and disable unnecessary services.
