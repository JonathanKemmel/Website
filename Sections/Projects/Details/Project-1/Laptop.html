Arch Linux Installation & Configuration

Full Guide
  • Create a Ventoy USB, verify the Arch ISO (SHA256) and boot the live environment.
  • Partition the disk (EFI + root), create filesystems and mount them.
  • Perform base installation and update packages (pacman -Syu).
  • Create a normal user, add to the wheel group and enable sudo.
  • Enable SSH and apply basic firewall rules for remote access.
  • Configure swap or zram and disable unnecessary services to save resources.
  • Install essential packages: python, git, esphome, and a lightweight browser.

IDE Setup for Low-Resource Development

Full Guide
  • Hardware note: Lenovo G50-45, Arch Linux, 4GB RAM, HDD — optimize for low resources.
  • Prefer lightweight editors: Neovim, Geany, or code-server for remote editing.
  • If using VS Code, disable telemetry, auto-update and heavy extensions; exclude large folders from watcher.
  • Use virtual environments for Python projects and keep dependencies minimal.
  • Install ESPHome in a venv and use PlatformIO only if needed for firmware builds.
  • Limit file watchers/indexing and disable editor features that consume RAM/IO.
  • Use git for version control and simple sync (rsync) for project backups.
  • Monitor RAM/IO and tune swap/zram; remove unused services to free resources.
