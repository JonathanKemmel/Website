Arch Linux Installation & Configuration

BIOS / Firmware Setup:

  • Boot into BIOS
  • Enabled AMD SVM support (optional)
  • Set boot mode: UEFI
  • Disabled unnecessary devices or secure boot for simplicity
  • Hotkey Mode left default

Prepare Installation Media:

  • Created Ventoy USB drive
  • Copied latest Arch Linux ISO
  • Verified ISO integrity (SHA256)

Booting & Disk Setup:

  • Booted from "EFI USB Device"
  • Verified live environment:
    1. lsblk shows sda as HDD
    2. ls /sys/firmware/efi → directory does not exist (legacy/BIOS fallback)
  • Wiped HDD using:
    1. wipefs -a /dev/sda
    2. Optional: sgdisk --zap-all /dev/sda
  • Partitioning:
    1. Type: GPT
    2. Created EFI + root partitions
  • Filesystem:
    1. Ext4 on root
    2. EFI: FAT32
    3. Optional: zRAM swap enabled

Install base system via archinstall tool:

  • Installed base system via archinstall tool
  • Chose:
    1. Disk: sda
    2. Filesystem: ext4
    3. Bootloader: systemd-boot
    4. Timezone: Europe/Berlin
    5. Keyboard layout: de
  • Encountered package signature errors:
    1. Resolved by updating ISO and skipping verification during install
  • Confirmed installation:
    1. arch-chroot /mnt
    2. System boots into installed Arch Linux

User & Root Management:

  • Create normal user:
    1. sudo useradd -m -G wheel username
    2. sudo passwd username
  • Enable sudo for wheel group:
    1. sudo EDITOR=nano visudo
    2. Uncomment: %wheel ALL=(ALL:ALL) ALL
  • SSH / GUI login:
    1. Log in as normal user
    2. Use sudo / pkexec for root actions

Install and configure OpenSSH:

  • Install OpenSSH:
    1. sudo pacman -S openssh
  • Enable SSH daemon:
    1. sudo systemctl enable sshd
    2. sudo systemctl start sshd
    3. sudo systemctl status sshd # verify
  • Firewall (if ufw used):
    1. sudo ufw allow 22/tcp
  • SSH login recommendations:
    1. Use a normal user for login
    2. Avoid root login over SSH for security
  • SSH configuration file:
    1. sudo nano /etc/ssh/sshd_config
    2. Key line: PermitRootLogin no
  • Restart SSH after edits:
    1. sudo systemctl restart sshd

XFCE Root Login Handling:

  • Root login in XFCE4 is disabled by default. Recommended: log in as normal user and use sudo/pkexec for root tasks
  • Optional: enable manual root login in LightDM:
    1. sudo nano /etc/lightdm/lightdm.conf
    2. Add under [Seat:*]: greeter-show-manual-login=true
  • Set root password (if needed):
    1. sudo passwd root
  • Restart LightDM:
    1. sudo systemctl restart lightdm
  • Run apps as root safely:
    1. sudo thunar # file manager
    2. pkexec gparted # gparted

Disabling System Sounds / Bell:

  • Terminal bell test:
    1. echo -e "\a"
  • Disable PC speaker permanently:
    1. sudo rmmod pcspkr
    2. echo "blacklist pcspkr" | sudo tee /etc/modprobe.d/nobeep.conf
  • Disable audible bell in terminal:
    1. Add to ~/.inputrc: set bell-style none
    2. Reload: bind -f ~/.inputrc
  • XFCE GUI sound:
    1. Settings → Notifications → disable event sounds
    2. Settings → Keyboard → Behavior → uncheck "Audible bell"
  • Optional: mute all system audio:
    1. PulseAudio: pactl set-sink-mute @DEFAULT_SINK@ 1
    2. PipeWire: pw-cli set-node-volume <node_id> 0

Network Configuration:

  • Switched to NetworkManager for simplicity:
    1. sudo systemctl enable NetworkManager
    2. sudo systemctl start NetworkManager

Post-Install Essentials / Packages:

IDE Setup for Low-Resource Development

Hardware Specifications:

  • Hardware: Lenovo G50-45
  • OS: ArchLinux
  • RAM: 4GB
  • Storage: HDD

Step 1: Install VS Code Insiders (bare minimum):

  • sudo pacman -S code-insiders

Step 2: Configure VS Code Insiders for Low RAM / HDD:

  • Create or edit ~/.config/Code - Insiders/User/settings.json:
    1. {
        "telemetry.enableTelemetry": false,
        "telemetry.enableCrashReporter": false,
        "update.mode": "none",
        "files.watcherExclude": {
          "**/.git/objects/**": true,
          "**/.git/subtree-cache/**": true,
          "**/node_modules/**": true
        },
        "editor.minimap.enabled": false
      }
  • Install only necessary extensions:
    1. PlatformIO IDE (ESPHome)
    2. Live Server (Web dev)
    3. YAML (optional, for ESPHome YAML)

Step 3: Set up ESPHome:

  • Create folder and virtual environment:
    1. mkdir ~/esphome
    2. cd ~/esphome
    3. python -m venv venv
  • Activate virtual environment:
    1. source venv/bin/activate
  • Upgrade pip inside venv (optional):
    1. pip install --upgrade pip
  • Install ESPHome inside venv:
    1. pip install esphome
  • Verify installation:
    1. esphome version

Step 4: Install PlatformIO Core inside venv:

  • With the venv active:
    1. pip install platformio
    2. platformio --version
  • PlatformIO IDE in VS Code Insiders should now detect PlatformIO Core automatically
