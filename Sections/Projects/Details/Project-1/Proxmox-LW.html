Proxmox-LW (Lightweight Server)

Hardware:

  • AsRock E350M1 Motherboard
  • AMD E-350 Processor
  • 8GB DDR3 RAM (2x4GB)
  • 250GB SSD (OS)
  • 1TB HDD (Storage)
  • 90W PicoPSU + 12V Power Supply

Use Case:

  • Host lightweight applications
  • Low-power 24/7 operation
  • Easy service management via a user-friendly web interface
  • Scalability and flexibility for future expansion

Setup and Installation:

Full Guide
  • Create a bootable USB with the Proxmox VE ISO (Rufus/Etcher/Ventoy) and boot the target machine.
  • Select installation target, verify partitioning scheme and set a strong root password.
  • Configure networking (static IP recommended) and DNS according to your environment.
  • After first boot: update the host (apt update && apt upgrade).
  • Configure storage (LVM, ZFS or directories) and establish a backup plan.
  • Enable the QEMU guest agent on guests and create VM templates for common images.
  • Harden SSH, review firewall rules and consider enabling 2FA for web access.
  • Optionally set up centralized logs and monitoring (Prometheus/Grafana) for alerts.
  • Schedule regular maintenance tasks (updates, snapshots, backup verification).

Install MyDokuWiki:

Full Guide
  • Create an LXC container from a suitable Ubuntu template (unprivileged recommended).
  • Verify SSH access, apply base updates and create required user accounts.
  • Install Apache2 and PHP with recommended modules (php-gd, php-xml, php-mbstring).
  • Download DokuWiki to /var/www/html and set correct filesystem permissions.
  • Configure a VirtualHost and reload the web server.
  • Verify storage options—DokuWiki uses the filesystem; plan backups accordingly.
  • Allow HTTP/HTTPS in UFW and secure the site with HTTPS (Let's Encrypt).
  • Automate regular backups of DokuWiki directories and configuration files.
  • Set proper user permissions and ACLs for content directories.

MyDokuWiki USB Backup:

Full Guide
  • Attach the USB drive to the host and identify it with lsblk.
  • Create a mount point (e.g. /mnt/usb) and set appropriate permissions.
  • Perform a test backup with vzdump for a VM and verify integrity.
  • Create a script to mount the drive, run the backup, and safely unmount the media.
  • Ensure backups are stored securely or encrypted if required.
  • Schedule a cron job and define a retention policy (daily/weekly rotations).
  • Set up monitoring/alerts to notify on backup failures.

Install Tailscale VPN Server:

Full Guide
  • Install the Tailscale package or use the community helper script.
  • Sign in with your Tailscale account and authorize devices.
  • Optionally enable subnet routing if you need to expose network segments.
  • Review firewall and routing configurations to avoid conflicts.
  • Test connectivity (ping, SSH) over the Tailscale network.
  • Use ACLs to restrict access to specific services as needed.

Setup Debian 12 VM template:

Full Guide
  • Install Debian, enable SSH and update the system.
  • Install standard tools (SSH, sudo, cron, monitoring agents).
  • Test configuration and disable services that are not required.
  • Shut down the VM and convert it to a template in the Proxmox GUI.
  • Clone the template, test the image and apply adjustments if necessary.

Setup HDD as SMB-Share:

Full Guide
  • Attach the drive and identify it with lsblk.
  • Partition/format the drive (EXT4 or preferred FS) and mount it.
  • Install Samba and create shares in /etc/samba/smb.conf.
  • Create users/passwords for network access and set filesystem permissions.
  • Restart the Samba service and test access from a client (Windows/NAS).
  • Review and secure firewall rules for SMB ports.
