NAS - Detailed Guide

Operating System Installation

Prepare ISO

  • Download Debian 13 netinst ISO
  • Write to Ventoy USB Drive

BIOS Settings

  1. Boot into BIOS
  2. Enable AHCI (not RAID) for NVMe
  3. Enable UEFI boot (recommended)
  4. Disable Secure Boot
  5. Save & reboot into USB installer

Debian 13 Minimal Install

Boot installer:

  • Select Install
  • Choose language, country, keyboard layout

Network Configuration:

  • Select network interface (Ethernet preferred)
  • If using DHCP, automatically IP
  • If static IP:
IP: 192.168.X.XXX
Netmask: 255.255.255.0
Gateway: 192.168.X.1
DNS: 8.8.8.8

Set Hostname & Domain:

  • Hostname: nas-server
  • Domain: leave empty

Set Root & User:

  • Root password: strong one
  • Create a user: admin

Partition Disk:

  • Guided → use entire disk
  • Optional, choose LVM if expanded in future
  • Confirm changes and write partitions

Package Selection:

Deselect all except:

  • SSH server
  • Standard system utilities

Do not install desktop environments for minimal OMV!!!

Install GRUB:

  • Install GRUB on main disk (/dev/nvme0n1)
  • Confirm installation

Finish & Reboot:

  • Remove USB and reboot
  • Log in with your user or root

Post-Install Essentials

Update & Upgrade:

sudo apt update && apt upgrade -y
sudo reboot

Enable SSH

sudo systemctl enable ssh
sudo systemctl start ssh

Install required tools

sudo apt install -y sudo curl gnupg lsb-release

Install OpenMediaVault

Note: OMV 7 is designed for Debian 13

Add OMV Repo

sudo curl -fsSL https://packages.openmediavault.org/public/archive.key | sudo gpg --dearmor -o /etc/apt/trusted.gpg.d/openmediavault.gpg
echo "deb https://packages.openmediavault.org/public arrakis main" | sudo tee /etc/apt/sources.list.d/openmediavault.list
sudo apt update

Install OMV

sudo apt install openmediavault-keyring postfix -y
sudo apt update
sudo apt install openmediavault -y

Initialize OMV

sudo omv-initsystem

Access OMV Web GUI

Default URL

http://<your-server-ip>/

Default credentials

  • Username: admin
  • Password: openmediavault

⚠️ Change password immediately after login

Post-OMV Configuration

Network

  • Configure static IP if not done
  • Disable IPv6 if unused

Storage

  • Add drives under Storage > Disks
  • Wipe and create file systems (EXT4 recommended for simplicity)

Shared Folders

  • Create shared folders on drives
  • Assign permissions

SMB / NFS / FTP

  • Enable desired services under Services
  • Create users for network access

Updates

  • Regularly check System > Update Management

Optional

  • Docker Plugin (omv-extras) for containers
  • SnapRAID / MergerFS if needed for advanced storage
