NAS — Full Detailed Guide

Debian Installation (Detailed)

  1. Download Debian netinst ISO and write it to a Ventoy USB drive.
  2. Boot installer, configure language/keyboard and network (static IP recommended).
  3. Partition disks (guided or custom), consider LVM for flexibility.
  4. Install minimal system, enable SSH during package selection.
  5. Install GRUB to the main disk and reboot into the new system.

OpenMediaVault Installation

  1. Add OMV repository keys and repository as documented by OMV.
  2. Install openmediavault packages and initialize the system (omv-initsystem).
  3. Open the OMV web GUI, change admin password and configure storage modules.
  4. Create Shared Folders and user accounts for SMB/NFS access.

Storage & Shares

  • Manage disks via OMV → Storage: wipe if needed, create filesystems, mountpoints.
  • Use EXT4 for simplicity or plan RAID/LVM for redundancy/performance.
  • Enable SMB and NFS services, configure permissions and test from clients.

Maintenance

  • Schedule updates and backups; consider offsite copies for critical data.
  • Monitor disk health (SMART) and plan replacements before failure.
  • Document share mappings and backup procedures.
