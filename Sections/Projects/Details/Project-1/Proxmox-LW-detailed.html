Proxmox — Lightweight Guide

Operating System

Prepare media and a minimal Debian 13 netinst for Proxmox VE (lightweight host).

Prepare ISO

  • Download Debian 13 netinst ISO and verify its checksum (SHA256).
  • Write the ISO to a USB drive.

BIOS Settings

  • Boot into BIOS.
  • Enable AHCI for storage.
  • Enable VT-x / AMD-V virtualization.
  • Enable UEFI boot (recommended) and disable Secure Boot.
  • Save & reboot into the USB installer.

Debian 13 Minimal Install

  1. Boot the installer and select Install. Choose language, country and keyboard layout.
  2. Network Configuration: select the network interface (Ethernet preferred). If DHCP is used, an IP is assigned automatically.
  3. If using a static IP, use these placeholders:
IP: 192.168.X.XXX
Netmask: 255.255.255.0
Gateway: 192.168.X.1
DNS: 8.8.8.8
  1. Set hostname: proxmox-lw. Leave domain empty.
  2. Set a strong root password and create an admin user.
  3. Partition disk: Guided → use entire disk. Optionally choose LVM for future expansion. Confirm changes and write partitions.
  4. Package selection: deselect desktop environments. Select only SSH server and standard system utilities.
  5. Install GRUB on the main disk, confirm and finish.
  6. Remove USB, reboot and log in with your user or root.

Post-Install Essentials

  • Update & Upgrade:
sudo apt update && sudo apt upgrade -y
sudo reboot
  • Enable SSH:
sudo systemctl enable ssh
sudo systemctl start ssh

Install Proxmox VE

sudo apt install -y wget gnupg
wget -qO - https://enterprise.proxmox.com/debian/pve-enterprise-repo.gpg | sudo apt-key add -
echo "deb https://download.proxmox.com/debian/pve bookworm pve-no-subscription" | sudo tee /etc/apt/sources.list.d/pve-install-repo.list
sudo apt update
sudo apt install proxmox-ve -y

Post-Proxmox Configuration

  • Access the web GUI at https://<your-server-ip>:8006/
  • Configure storage, networking bridges and enable necessary services.
  • Apply updates and configure backups as required.

Proxmox VE — Detailed Guide

Setup & Installation

This guide documents the full steps I used to install and configure Proxmox VE.

  1. Download the latest Proxmox VE ISO from the official site.
  2. Create a bootable USB (Rufus/Etcher/Ventoy) and verify the image checksum.
  3. Boot the target machine from USB and follow the installer prompts.
  4. Choose installation disk and partitioning scheme (LVM or ZFS depending on needs).
  5. Set a strong root password and the management IP (static recommended).
  6. Complete installation and reboot the host.
  7. Access the web UI via https://:8006 and login as root.

Post-Install Configuration

  • Update the host: apt update && apt full-upgrade -y.
  • Enable the QEMU guest agent on guests for better management.
  • Configure storage: add LVM, ZFS pool or directory storage as needed.
  • Create VM templates for common guest OSes to speed up deployments.
  • Set up backups (vzdump) and test restore procedures regularly.
  • Harden SSH (disable root login over SSH, use keys), enable 2FA where useful.
  • Consider monitoring (Prometheus/Grafana) and log collection for alerts.

Useful Commands

  • Update host: apt update && apt full-upgrade -y
  • List VMs: qm list
  • Backup VM: vzdump --mode snapshot --compress lzo
  • Restore backup: qmrestore or vzrestore (depending on format)

Advanced Topics

  • Consider ZFS for data integrity and snapshots if storage and RAM allow.
  • Use Ceph or shared storage for HA setups (complex, requires planning).
  • Automate provisioning with cloud-init templates and configuration management.
