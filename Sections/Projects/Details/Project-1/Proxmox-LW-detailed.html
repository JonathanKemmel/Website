Proxmox VE — Detailed Guide

Setup & Installation

This guide documents the full steps I used to install and configure Proxmox VE.

  1. Download the latest Proxmox VE ISO from the official site.
  2. Create a bootable USB (Rufus/Etcher/Ventoy) and verify the image checksum.
  3. Boot the target machine from USB and follow the installer prompts.
  4. Choose installation disk and partitioning scheme (LVM or ZFS depending on needs).
  5. Set a strong root password and the management IP (static recommended).
  6. Complete installation and reboot the host.
  7. Access the web UI via https://:8006 and login as root.

Post-Install Configuration

  • Update the host: apt update && apt full-upgrade -y.
  • Enable the QEMU guest agent on guests for better management.
  • Configure storage: add LVM, ZFS pool or directory storage as needed.
  • Create VM templates for common guest OSes to speed up deployments.
  • Set up backups (vzdump) and test restore procedures regularly.
  • Harden SSH (disable root login over SSH, use keys), enable 2FA where useful.
  • Consider monitoring (Prometheus/Grafana) and log collection for alerts.

Useful Commands

  • Update host: apt update && apt full-upgrade -y
  • List VMs: qm list
  • Backup VM: vzdump --mode snapshot --compress lzo
  • Restore backup: qmrestore or vzrestore (depending on format)

Advanced Topics

  • Consider ZFS for data integrity and snapshots if storage and RAM allow.
  • Use Ceph or shared storage for HA setups (complex, requires planning).
  • Automate provisioning with cloud-init templates and configuration management.
