NAS (Network Attached Storage)

Hardware:

  • ASUS PRIME A320M-K Motherboard
  • AMD Ryzen 5 2600 (6-Core)
  • 16GB DDR4 RAM (2x8GB Corsair)
  • 250GB NVMe SSD (OS)
  • 4TB HDD (Storage)
  • 2TB HDD (Storage)
  • NVIDIA GeForce GT 710
  • Aerocool GEH Mini CS-110

Use Case:

  • Centralized file storage for multiple devices
  • Backup solution
  • Low power consumption 24/7 operation
  • Easy management via OpenMediaVault web interface

Content:

  • Debian Installation
  • Install OpenMediaVault
  • Configure Storage
  • Setup Shared Folders

Debian Installation:

Full Guide
  • Boot the Debian installer and choose "Install"; select language, country and keyboard layout.
  • Network: prefer Ethernet. Use DHCP or set a static IP (placeholder: IP 192.168.x.x, Netmask 255.255.255.0, Gateway 192.168.x.1, DNS 8.8.8.8).
  • Set hostname to omvserver and leave domain empty.
  • Set a strong root password and create an administrative user (e.g. admin).
  • Partition: choose Guided → use entire disk; optionally enable LVM for future expansion.
  • Package selection: deselect desktop environments; select only "SSH server" and "standard system utilities" for a minimal OMV host.
  • Install the bootloader (GRUB) on the main disk (example: /dev/nvme0n1) and confirm.
  • Finish installation, remove installer media and reboot into the new system.
  • Log in as your user or root and update the system: apt update && apt upgrade -y.

Install OpenMediaVault:

Full Guide
  • Note: OMV 7 targets Debian 13 — prefer matching OS version.
  • Import OMV repository and archive key, then run apt update.
  • Install OMV packages and required dependencies (postfix, openmediavault).
  • Run omv-initsystem to initialize configuration.
  • Open the OMV web GUI at http://<server-ip> and change the default admin password.
  • Configure storage backends, users and shared folders from the GUI.
  • Enable desired services (SMB/NFS/FTP) and set access permissions.
  • Install `omv-extras` if you need Docker/Plugins (optional).

Configure Storage:

Full Guide
  • Set a static IP for reliable access and disable IPv6 if unused.
  • Add drives in OMV → Storage → Disks and wipe if reusing media.
  • Create filesystems (EXT4 or your chosen FS) and set mountpoints.
  • Consider RAID/LVM/ZFS depending on redundancy and performance needs.
  • Enable SMART monitoring and schedule periodic SMART tests.
  • Plan backups and retention; test restores regularly.

Setup Shared Folders:

Full Guide
  • Create shared folders on the chosen mountpoints and assign permissions per user/group.
  • Enable SMB and/or NFS services and configure exports/shares.
  • Create users for network access and use strong passwords or external auth.
  • Set quotas or ACLs if you need per-user limits.
  • Enable update management and check for plugin updates periodically.
  • Optional: install Docker via omv-extras and advanced storage tools (SnapRAID/MergerFS).
