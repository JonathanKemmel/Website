qutebrowser Minimal Key Cheat Sheet

1️⃣ Modes

Key Action
Esc Go back to Normal mode
i Enter Insert mode (forms)
: Enter Command mode
v Enter Caret mode (select text)

2️⃣ Scrolling / Moving

Key Action
j / k Scroll down / up (small step)
d / u Scroll half-page down / up
gg / G Jump top / bottom of page
h / l Scroll left / right (if wide page)

3️⃣ Tabs

Key Action
Ctrl+t New tab
Ctrl+w Close tab
J / K Next / previous tab
Ctrl+Shift+t Reopen closed tab
:tab-focus N Jump to tab N

4️⃣ Link Navigation (Hint Mode)

Key Action
f Open link in current tab
F Open link in new tab
af Open link in background tab
yf Copy link URL to clipboard
Tip: After pressing f/F, type the letters shown on the link hints.

5️⃣ Search

Key Action
/text Search forward
?text Search backward
n / N Next / previous match

6️⃣ Page & URL

Key Action
r / R Reload / Reload ignoring cache
yy Copy current URL
pp Open URL from clipboard

7️⃣ Zoom

Key Action
+ / - Zoom in / out
= Reset zoom

8️⃣ Command Mode Essentials

Command Purpose
:open URL Open website
:quit Quit browser
:bookmark-add Add bookmark
:history Show history
:set Change a setting
:bind See all keybindings
