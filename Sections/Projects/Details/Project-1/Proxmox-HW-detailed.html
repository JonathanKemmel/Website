Proxmox — Hardware Guide

Operating System

Prepare media and a minimal Debian 13 netinst for Proxmox VE.

Prepare ISO

  • Download Debian 13 netinst ISO and verify its checksum (SHA256).
  • Write the ISO to a USB drive.

BIOS Settings

  • Boot into BIOS.
  • Enable AHCI for storage.
  • Enable VT-x / AMD-V virtualization.
  • Enable UEFI boot (recommended) and disable Secure Boot.
  • Save & reboot into the USB installer.

Debian 13 Minimal Install

  1. Boot the installer and select Install. Choose language, country and keyboard layout.
  2. Network Configuration: select the network interface (Ethernet preferred). If DHCP is used, an IP is assigned automatically.
  3. If using a static IP, use these placeholders:
IP: 192.168.X.XXX
Netmask: 255.255.255.0
Gateway: 192.168.X.1
DNS: 8.8.8.8
  1. Set hostname: proxmox-hw. Leave domain empty.
  2. Set a strong root password and create an admin user.
  3. Partition disk: Guided → use entire disk. Optionally choose LVM for future expansion. Confirm changes and write partitions.
  4. Package selection: deselect desktop environments. Select only SSH server and standard system utilities.
  5. Install GRUB on the main disk, confirm and finish.
  6. Remove USB, reboot and log in with your user or root.

Post-Install Essentials

  • Update & Upgrade:
sudo apt update && sudo apt upgrade -y
sudo reboot
  • Enable SSH:
sudo systemctl enable ssh
sudo systemctl start ssh

Install Proxmox VE

sudo apt install -y wget gnupg
wget -qO - https://enterprise.proxmox.com/debian/pve-enterprise-repo.gpg | sudo apt-key add -
echo "deb https://download.proxmox.com/debian/pve bookworm pve-no-subscription" | sudo tee /etc/apt/sources.list.d/pve-install-repo.list
sudo apt update
sudo apt install proxmox-ve -y

Post-Proxmox Configuration

  • Access the web GUI at https://<your-server-ip>:8006/
  • Configure storage, networking bridges and enable necessary services.
  • Apply updates and configure backups as required.

Proxmox HW — Full Details

Create Ubuntu VM (Detailed)

  1. Upload the Ubuntu ISO to Proxmox: Datacenter → Storage (local) → ISO Images → Upload.
  2. Create a VM: set name, VM ID, OS type and point to the uploaded ISO.
  3. System tab: set BIOS/UEFI as required, enable QEMU guest agent for better control.
  4. Disk: choose size and format (qcow2 for space-efficiency, raw for speed).
  5. CPU/Memory: allocate according to workload (e.g., 4 cores / 8GB for dev VM).
  6. Network: select bridge (vmbr0) and model (virtio) for performance.
  7. Start VM and run through the Ubuntu installer; then install guest tools and updates.
  8. Optional: install Docker and code-server for remote development use.

Create Kali VM (Detailed)

  1. Upload Kali ISO and create a VM as above.
  2. Use an isolated network bridge (e.g., vmbr1) to keep Kali separated from production LAN.
  3. Allocate resources and enable snapshots before performing risky tests.
  4. Keep Kali updated and only use it on systems/networks you own or have permission to test.

Post-install tips

  • Create VM templates for frequent deployments.
  • Use snapshots before major changes or security tests.
  • Document VM configurations so you can reproduce environments precisely.
