Proxmox HW — Full Details

Create Ubuntu VM (Detailed)

  1. Upload the Ubuntu ISO to Proxmox: Datacenter → Storage (local) → ISO Images → Upload.
  2. Create a VM: set name, VM ID, OS type and point to the uploaded ISO.
  3. System tab: set BIOS/UEFI as required, enable QEMU guest agent for better control.
  4. Disk: choose size and format (qcow2 for space-efficiency, raw for speed).
  5. CPU/Memory: allocate according to workload (e.g., 4 cores / 8GB for dev VM).
  6. Network: select bridge (vmbr0) and model (virtio) for performance.
  7. Start VM and run through the Ubuntu installer; then install guest tools and updates.
  8. Optional: install Docker and code-server for remote development use.

Create Kali VM (Detailed)

  1. Upload Kali ISO and create a VM as above.
  2. Use an isolated network bridge (e.g., vmbr1) to keep Kali separated from production LAN.
  3. Allocate resources and enable snapshots before performing risky tests.
  4. Keep Kali updated and only use it on systems/networks you own or have permission to test.

Post-install tips

  • Create VM templates for frequent deployments.
  • Use snapshots before major changes or security tests.
  • Document VM configurations so you can reproduce environments precisely.
