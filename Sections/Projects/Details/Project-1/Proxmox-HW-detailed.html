Proxmox HW - Detailed Guide

Create Ubuntu VM (Programming)

Upload ISO

Proxmox GUI → Datacenter → Storage(local) → ISO Images → Upload → choose Ubuntu ISO file

Create VM

Proxmox GUI → Create VM

  • Node: <your-host>
  • VM ID: auto
  • Name: ubuntu-dev

OS tab:

  • Use uploaded Ubuntu ISO
  • Leave other default

System tab:

  • BIOS: default (OVMF only if UEFI is needed)
  • Machine: default
  • Qemu Agent: checked (enables better shutdowns & status)

Disk tab:

  • Bus/Device: SCSI0 on VIRTIO-SCSI controller
  • Disk size: <your-choice>
  • Format: qcow2 or raw (raw slightly faster on SSD)

CPU tab:

  • Sockets: 1
  • Cores: 4 (2 if host smaller)

Memory tab:

  • Memory: 8192 (recommended for dev work)

Network tab:

  • Bridge: vmbr0
  • Model: VIRTIO (fast)

Finish → Start VM → Console → run Ubuntu installer

Post-install

Update the guest and install typical dev tools:

sudo apt update && sudo apt upgrade -y
sudo apt install -y build-essential git curl qemu-guest-agent

Install docker:

sudo apt install -y ca-certificates gnupg lsb-release
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /usr/share/keyrings/docker-archive-keyring.gpg
echo \\
    \"deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/docker-archive-keyring.gpg] \\
    https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable\" | \\
    sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io
sudo usermod -aG docker $USER

Install code-server (VS Code in browser) if remote IDE needed:

curl -fsSL https://code-server.dev/install.sh | sh

Make a template

  1. Once you're done, right click VM → clone
  2. Right click cloned VM → convert to template
  3. Now you're able to clone fresh dev VMs quick

Create Kali VM (Hacking)

Important safety note: Treat Kali as a risky toolkit. Keep it isolated from your main LAN. Only use it on systems/networks you own or have explicit permission to test.

Upload ISO

Proxmox GUI → Datacenter → Storage(local) → ISO Images → Upload → choose Kali ISO file

Create isolated network without physical NIC

Proxmox GUI → Datacenter → Node → System → Network → Create → Linux Bridge

  • Name: vmbr1
  • Leave rest empty

This way Kali can only talk to VMs on isolated Bridge (vmbr1)

Create VM

Proxmox GUI → Create VM

  • Node: <your-host>
  • VM ID: auto
  • Name: kali-lab

OS tab:

  • Use uploaded Kali ISO
  • Leave other default

System tab:

  • BIOS: default (OVMF only if UEFI is needed)
  • Machine: default
  • Qemu Agent: checked (enables better shutdowns & status)

Disk tab:

  • Bus/Device: SCSI0 on VIRTIO-SCSI controller
  • Disk size: <your-choice>
  • Format: qcow2 or raw (raw slightly faster on SSD)

CPU tab:

  • Sockets: 1
  • Cores: 4 (2 if host smaller)

Memory tab:

  • Memory: 8192 (recommended for dev work)

Network tab:

  • Bridge: vmbr1 (isolated bridge, no Network)
  • Model: VIRTIO (fast)

Finish → Start VM → Console → run Kali installer
