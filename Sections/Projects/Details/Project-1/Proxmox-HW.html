Proxmox HW (High-Performance Server)

Hardware:

  • Custom Build Workstation
  • Multi-Core Processor
  • 16GB+ RAM
  • SSD Storage
  • Dedicated Network Interface

Use Case:

  • Running resource-intensive applications
  • Development environments (Ubuntu VM)
  • Security testing (Kali VM)
  • On-demand high-performance computing

Content:

  • Create Ubuntu VM (Programming)
  • Create Kali VM (Hacking/Security)

Create Ubuntu VM (Programming)

Full Guide
  • Upload the Ubuntu ISO to your Proxmox storage (Datacenter → Storage → ISO Images).
  • Create a VM and assign CPU, RAM and disk size (choose qcow2 or raw).
  • Set the VM network to the cluster bridge (e.g. vmbr0) and use VIRTIO drivers.
  • Install the OS, enable SSH and apply system updates.
  • Install development tooling (build-essential, git; Docker optional).
  • Enable the QEMU guest agent inside the VM for better management.
  • Adjust VM cache and balloon settings only if you need extra performance tuning.
  • Convert the VM to a template for repeatable deployments when ready.

Create Kali VM (Hacking/Security)

Full Guide
  • Only run Kali on controlled lab networks where you have explicit permission.
  • Upload the Kali ISO to Proxmox storage (ISO Images).
  • Provide an isolated network (bridge or VLAN) for lab VMs to avoid production exposure.
  • Create the Kali VM and attach it to the isolated bridge (use VIRTIO network/devices).
  • Install the OS, then enable the QEMU guest agent inside the guest.
  • Take snapshots before running risky tests so you can roll back quickly.
  • Limit network exposure with firewall rules and strict ACLs.
  • Store backups and snapshots securely and keep a retention plan.
