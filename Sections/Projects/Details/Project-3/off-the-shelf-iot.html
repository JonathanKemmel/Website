Integration into HA

Full Guide

NOUS A1 Tuya Switches - Local Control via LocalTuya:

  • Create Tuya IoT Developer Account at iot.tuya.com
  • Create Cloud project and link Tuya/Smart Life app account
  • Get API credentials: Access ID & Access Secret
  • Retrieve Local Key & Device ID via API Explorer
  • Install LocalTuya integration via HACS in Home Assistant
  • Configure LocalTuya with Region, Client ID, Client Secret & UID
  • Add device using Device ID & Local Key
  • Switch now operates locally without cloud dependency

Notes

  • Check device capabilities: Verify power monitoring, energy tracking, and smart features before purchase
  • Communication protocol: Ensure device supports Zigbee, WiFi, or local control (not just cloud-only)
  • Firmware updates: Keep devices updated but test updates on non-critical devices first
  • Network isolation: Consider VLAN separation for IoT devices to improve security
  • Compatibility check: Verify Home Assistant integration support before buying new devices
  • Documentation: Keep track of Device IDs, Local Keys, and integration configs
