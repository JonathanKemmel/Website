NOUS A1 Tuya Switches - Local Control Integration

Option B — Local Control via LocalTuya (API‑KEY + Local Key)

If you want your switch to work locally (no cloud), you'll need its Local Key and Device ID. This approach uses the LocalTuya custom integration in Home Assistant.

1. Create a Tuya IoT Developer Account

  1. Go to https://iot.tuya.com and sign up for a developer account
  2. Navigate to Cloud → Development
  3. Create a new project
  4. Choose your Data Center region (e.g., Central Europe / EU)
  5. Link your Tuya/Smart Life app account to this project via QR code

2. Get API Credentials

In your Cloud project:

  1. Click on your project name
  2. Go to the Overview tab
  3. Copy your Access ID (Client ID)
  4. Copy your Access Secret (Client Secret)

Note: These are API credentials, similar to an API key. Keep them secure!

3. Retrieve Local Key and Device ID

Use Tuya's API Explorer in the IoT platform:

  1. Go to Cloud → API Explorer
  2. Choose service:
    • Smart Home Device System → Device Management → Get Device List
  3. Click Submit Request
  4. Look at the returned JSON — each device entry includes:
    • Device ID (id field)
    • Local Key (local_key field)
  5. Copy and store these values for your NOUS A1 switch

Example JSON response:

{
  "result": {
    "devices": [
      {
        "id": "bf1234567890abcdef",
        "local_key": "abc123def456",
        "name": "Smart Switch",
        ...
      }
    ]
  }
}

4. Install LocalTuya in Home Assistant

You need the LocalTuya integration via HACS:

Install HACS (if not already installed):

  1. Go to Settings → Add-ons → Add-on Store
  2. Install Terminal & SSH add-on
  3. Start Terminal and run:
wget -O - https://get.hacs.xyz | bash -
  1. Restart Home Assistant
  2. Go to Settings → Devices & Services → Add Integration
  3. Search for HACS and follow setup wizard

Install LocalTuya via HACS:

  1. Open HACS in Home Assistant sidebar
  2. Click Integrations
  3. Click the + Explore & Download Repositories button
  4. Search for LocalTuya
  5. Click Download
  6. Restart Home Assistant after installation

5. Configure LocalTuya

  1. Go to Settings → Devices & Services → Add Integration
  2. Search for LocalTuya
  3. In the config screen, enter:
    • Region: Select your data center region (e.g., EU)
    • Client ID: Your Access ID from step 2
    • Client Secret: Your Access Secret from step 2
    • Tuya App Account UID: Found in IoT portal's linked account section
  4. Click Submit and wait for connection

Get Tuya App Account UID:

  1. In Tuya IoT portal, go to Cloud → Development → Your Project
  2. Click Devices tab
  3. Look for UID field or check linked account details
  4. Alternatively, check the API response from "Get Device List" - it may include your UID

6. Add NOUS A1 Device

  1. Once LocalTuya is configured, click Configure on the LocalTuya integration
  2. Click Add new device
  3. LocalTuya should scan your local network and show your NOUS A1 switch
  4. If device is not automatically detected:
    • Choose Manual configuration
    • Enter Device ID from step 3
    • Enter Local Key from step 3
    • Enter device IP address (check your router's DHCP list)
  5. Click Submit

7. Configure Device Entities

  1. After adding the device, you'll configure its entities (what it controls)
  2. For NOUS A1 switch, typically you need:
    • Switch entity (DPS 1): Main power switch
    • Current (DPS 18): Current consumption in mA
    • Power (DPS 19): Power consumption in W
    • Voltage (DPS 20): Voltage in V
  3. Select entity type (switch, sensor) for each DPS (Data Point)
  4. Click Submit

Common DPS values for NOUS A1:

DPS 1: switch (boolean) - Main switch
DPS 9: countdown (integer) - Timer countdown
DPS 18: sensor (integer) - Current (mA)
DPS 19: sensor (integer) - Power (W × 10)
DPS 20: sensor (integer) - Voltage (V × 10)

8. Test the Device

  1. Go to Settings → Devices & Services
  2. Find your NOUS A1 device under LocalTuya integration
  3. Click on the device
  4. Test the switch entity by toggling it ON/OFF
  5. Check if power monitoring sensors update correctly

9. Add to Dashboard

  1. Go to your Home Assistant dashboard
  2. Click Edit Dashboard
  3. Click Add Card
  4. Choose card type (e.g., Entities or Button)
  5. Select your NOUS A1 switch entity
  6. Customize name, icon if desired
  7. Save

10. Create Automations (Optional)

Example: Turn on switch at sunset

  1. Go to Settings → Automations & Scenes
  2. Click Create Automation
  3. Set trigger: Sun → Sunset
  4. Set action: Call service → switch.turn_on
  5. Select your NOUS A1 switch entity
  6. Save automation

Troubleshooting

Device not found during scan:

  • Ensure device is powered on and connected to same network as Home Assistant
  • Check if device IP is reachable: ping <device-ip>
  • Try manual configuration with Device ID and Local Key
  • Set static IP for device in your router

Device shows as unavailable:

  • Verify Local Key is correct (it can change if device is reset or re-paired)
  • Check if device firmware was updated (may change protocol)
  • Restart LocalTuya integration
  • Restart Home Assistant

Entities not updating:

  • Verify DPS configuration matches your device model
  • Check LocalTuya logs: Settings → System → Logs
  • Try removing and re-adding the device

Local Key retrieval fails:

  • Ensure Tuya app account is properly linked to IoT project
  • Check data center region matches your account region
  • Verify API permissions in Cloud project settings
  • Try using Tuya CLI tool as alternative: tuya-cli wizard

Benefits of Local Control

  • ✓ No internet required - Works during internet outages
  • ✓ Faster response time - Direct local communication
  • ✓ Privacy - No data sent to Tuya cloud
  • ✓ Reliability - Not dependent on Tuya's servers
  • ✓ Better integration - Native Home Assistant control

Notes

  • Keep your API credentials and Local Keys secure
  • If device is factory reset, you'll need to retrieve the Local Key again
  • Some Tuya devices may use different DPS values - check device documentation or HACS community forums
  • LocalTuya requires devices to be on same network subnet as Home Assistant
  • Regular firmware updates may require reconfiguration
