Home Assistant - Detailed Guide

Home Assistant Setup & Installation

1. Hardware Preparation

Required Hardware:

  • Raspberry Pi 5 (8GB RAM recommended)
  • 1TB SSD - For Home Assistant OS and data storage
  • USB to SATA Adapter - Connect SSD to Raspberry Pi
  • Power Supply - Official Pi 5 PoE HAT or USB-C power adapter (27W)
  • Sonoff USB ZBDongle-E - For Zigbee device communication
  • Ethernet Cable - For stable network connection (recommended)

2. Download Home Assistant OS

  1. Visit the official Home Assistant website: https://www.home-assistant.io/installation/
  2. Select Raspberry Pi as installation method
  3. Download the Home Assistant OS image for Raspberry Pi 5 (64-bit)
  4. Verify image checksum (SHA256) to ensure download integrity

3. Flash Image to SSD

Using Balena Etcher (Recommended):

  1. Download and install Balena Etcher from balena.io/etcher
  2. Connect SSD to your computer via USB adapter
  3. Open Balena Etcher and select the downloaded Home Assistant OS image
  4. Select your SSD as target drive (be careful not to select wrong drive!)
  5. Click Flash! and wait for process to complete (5-10 minutes)
  6. Safely eject SSD when done

Alternative: Raspberry Pi Imager

1. Download Raspberry Pi Imager
2. Choose OS → Other specific-purpose OS → Home Assistants
3. Select your SSD
4. Write image

4. Initial Boot & Setup

  1. Connect SSD to Raspberry Pi via USB adapter
  2. Connect Ethernet cable to Pi (recommended for initial setup)
  3. Connect power supply and boot up Raspberry Pi
  4. Wait for initial Home Assistant installation (can take 5-20 minutes)
  5. Check your router for assigned IP address or use mDNS discovery

5. Access Web Interface

Open browser and navigate to one of these addresses:

http://homeassistant.local:8123
or
http://<raspberry-pi-ip>:8123

Note: First time access may show "Preparing Home Assistant" - be patient!

6. Create User Account

  1. Enter your Name
  2. Create a Username
  3. Set a strong Password
  4. Confirm password

Important: This is your admin account - use a strong password!

7. Configure Location & Timezone

  • Set your Home Location on the map (or enter address)
  • Select Timezone (e.g., Europe/Berlin)
  • Choose Unit System (Metric or Imperial)
  • Select Currency for energy monitoring

8. Enable Advanced Mode

  1. Click your username in bottom left corner
  2. Scroll down to Advanced Mode
  3. Toggle ON

This enables advanced settings and developer tools

9. Configure Zigbee USB Dongle

Install Zigbee2MQTT Add-on:

  1. Go to Settings → Add-ons → Add-on Store
  2. Search for Zigbee2MQTT
  3. Click Install and wait for completion
  4. Go to Configuration tab
  5. Set serial port:
serial:
  port: /dev/ttyUSB0
  1. Start the add-on and enable Start on boot
  2. Check logs for successful Zigbee coordinator connection

10. Install HACS (Home Assistant Community Store)

Installation Steps:

  1. Install Terminal & SSH add-on from Add-on Store
  2. Start Terminal and open web UI
  3. Run HACS installation command:
wget -O - https://get.hacs.xyz | bash -
  1. Restart Home Assistant: Settings → System → Restart
  2. After restart, go to Settings → Devices & Services
  3. Click + Add Integration and search for HACS
  4. Follow setup wizard and authorize with GitHub account
  5. HACS is now available in sidebar

11. Set Up Automatic Backups

Configure Backup Schedule:

  1. Go to Settings → System → Backups
  2. Click Create Backup for initial backup
  3. Install Google Drive Backup from HACS (optional)
  4. Or use Samba Share add-on for network backups

Samba Share Setup:

1. Install Samba Share add-on
2. Configure username and password
3. Start add-on
4. Access backups at \\homeassistant\backup

12. Essential Add-ons to Install

  • File Editor - Edit configuration.yaml in browser
  • Mosquitto Broker - MQTT server for device communication
  • Terminal & SSH - Command-line access
  • Studio Code Server - Full VS Code IDE in browser
  • Node-RED - Visual automation editor (optional)

13. Configure SSL/HTTPS (Optional)

Using DuckDNS Add-on:

  1. Create account at duckdns.org
  2. Install DuckDNS add-on
  3. Configure with your domain and token
  4. Start add-on - automatically gets Let's Encrypt certificate
  5. Update configuration.yaml:
http:
  ssl_certificate: /ssl/fullchain.pem
  ssl_key: /ssl/privkey.pem
  1. Restart Home Assistant
  2. Access via https://yourdomain.duckdns.org:8123

14. First Automations

Create Simple Automation:

  1. Go to Settings → Automations & Scenes
  2. Click Create Automation
  3. Choose trigger (e.g., sunset)
  4. Choose action (e.g., turn on lights)
  5. Save and test automation

15. Performance Optimization

  • Disable unused integrations in Settings → Integrations
  • Set recorder purge days in configuration.yaml:
recorder:
  purge_keep_days: 7
  commit_interval: 30
  • Move database to SSD if using SD card
  • Monitor system health: Settings → System → System Health

16. Security Best Practices

  • Use strong passwords for all accounts
  • Enable Two-Factor Authentication (2FA) for your account
  • Don't expose Home Assistant directly to internet without VPN
  • Use Tailscale or WireGuard VPN for remote access
  • Regularly update Home Assistant and all add-ons
  • Review Settings → System → Logs for suspicious activity
